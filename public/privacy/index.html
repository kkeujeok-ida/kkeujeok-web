Kkeujeok 개인정보처리방침

적용 대상과 시행일

이 방침은 필기 앱 Kkeujeok(Android 앱과 웹 앱, 이하 "앱")에 적용돼요. 2026년 11월 16일부터 시행해요. 앱의 운영자는 Kkeujeok 개발팀이에요.

앱이 접근하는 Google 사용자 데이터

앱은 Google 로그인으로 계정의 고유 식별자(sub)와 이메일 주소를 확인하고, Google Drive 권한 중 drive.file 하나를 요청해요. drive.file은 Kkeujeok이 만들었거나 사용자가 앱에서 직접 연 파일만 다룰 수 있는 권한이에요. Drive에 있는 다른 파일은 볼 수 없어요.

데이터를 쓰는 방법

이 데이터는 사용자가 요청한 기능을 제공하는 데만 써요. 노트를 사용자의 Drive에 저장하고, 불러오고, 기기 사이에 동기화하고, 로그인한 계정을 보여 주는 데 써요. 그 밖의 목적으로는 쓰지 않아요.

공유와 제3자 제공

운영자는 Google 사용자 데이터를 받지 않아요. 앱은 사용자의 기기나 브라우저에서 Google 서버와 직접 통신해요. 데이터를 제3자에게 판매하거나 제공하거나 공개하지 않아요. 노트를 내보내거나 공유하는 일은 사용자가 직접 선택할 때만 일어나요.

Google API 서비스 사용자 데이터 정책(Limited Use)

Kkeujeok이 Google API로 받은 정보를 다른 앱으로 전달할 때는 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따라요. Google 사용자 데이터를 맞춤 광고, 리타깃팅 광고, 관심 기반 광고에 쓰지 않아요. 데이터 중개업체나 정보 재판매업체에 팔거나 제공하지 않아요. 신용 평가나 대출 판단에 쓰지 않아요. 별도의 데이터베이스를 만드는 데 쓰지 않아요. 운영자가 노트를 받지 않으므로 사람이 노트를 읽는 일도 없어요.

Google API 서비스 사용자 데이터 정책

AI·머신러닝

Google Workspace API로 얻은 정보를 일반(비개인화) AI·머신러닝 모델을 개발하거나 개선하거나 학습시키는 데 쓰지 않아요. 앱에는 노트를 분석하는 AI 기능도 없어요.

저장 위치와 보호

노트는 사용자의 Google Drive에만 저장돼요. Kkeujeok에는 서버가 없고, 분석 도구와 크래시 리포팅도 쓰지 않아요. Google과의 통신은 HTTPS로 이뤄져요. 웹 앱의 액세스 토큰은 브라우저 메모리에만 있고 저장하지 않아요. 노트 파일의 저장과 보호는 Google Drive가 맡아요. Kkeujeok이 노트를 따로 암호화하지는 않아요.

기기에 저장되는 정보

앱은 오프라인 사용과 빠른 표시를 위해 노트의 사본을 기기나 브라우저에 임시로 보관할 수 있어요. 웹 앱은 이 브라우저에서 이전에 로그인했다는 표시로 계정 식별자와 이메일을 로컬 저장소에 남겨요. 로그아웃하거나 연결을 해제하면 이 표시를 지워요.

보관과 삭제

Kkeujeok이 운영자 쪽에 보관하는 사용자 데이터는 없어요. 노트는 사용자가 Drive에서 지울 때까지 사용자의 Drive에 남아요. 노트를 지우고 싶으면 Google Drive에서 직접 삭제하면 돼요. 운영자가 보관하는 데이터가 없으므로 따로 삭제를 요청할 필요는 없어요. 기기에 남은 임시 사본은 앱을 삭제하거나 브라우저 사이트 데이터를 지우면 사라져요.

연결 해제와 권한 철회

설정에서 연결을 해제하면 Kkeujeok이 Drive 권한을 거둬요. Google 계정의 권한 페이지에서도 언제든 권한을 철회할 수 있어요. Drive의 노트 파일은 그대로 남아요.

Google 계정 권한 페이지

이 방침의 변경

앱이 Google 사용자 데이터를 다루는 방식이 바뀌면 이 페이지를 고치고, 앱이나 이 사이트에서 알려요. 바뀐 방침은 이 페이지에 게시한 때부터 적용돼요.
